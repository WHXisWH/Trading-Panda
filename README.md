### What is TradingPanda?

TradingPanda is an **AI trading pet system on Sui**. You mint a Panda NFT whose five-axis personality is generated by `sui::random` at mint time and permanently fixed on-chain. You feed it a trading strategy in plain language; it practices autonomously on a simulated order book, accumulates experience, and evolves emotionally based on wins and losses.

> *"You're not using an AI tool — you're raising a partner that learns to trade for you."*

→ Full product story: **[docs/product-description.md](docs/product-description.md)**

---

### Why Sui?

| Requirement | Sui solution |
|---|---|
| Immutable personality at mint | `sui::random` — consensus-layer randomness, zero extra cost |
| Dynamically growing experience | `dynamic_fields` — extend NFT state without changing the struct |
| Transfer lock during simulation | Object-level owned access — `assert!(panda.is_trading == false)` |
| Market with enforceable royalties | Sui Kiosk + `TransferPolicy<Panda>` — cannot be bypassed |
| Decentralised AI memory | Walrus — experience data stored off-chain, `blob_id` pointer on NFT |
| Verifiable decision logs | Merkle Root submitted on-chain every 50 trades |

### Running Locally

**Prerequisites:** Node.js 18+, Python 3.11+, Sui CLI, PostgreSQL database

**1. Backend**

```bash
cd backend
cp .env.example .env          # fill DATABASE_URL, REDIS_URL (Upstash: use rediss://…)
pip install -r requirements.txt
uvicorn main:app --reload     # http://localhost:8000
# Tables are created automatically on first start
```

**2. Frontend**

```bash
cd frontend
npm install
# .env.local is already committed with testnet contract addresses
npm run dev                   # http://localhost:3000
```

**3. Integration test flow**

1. Open `http://localhost:3000`
2. Connect a Sui testnet wallet (needs ~0.1 SUI)
3. Sign the login message → JWT issued
4. Go to `/mint` → sign the PTB → personality generated on-chain
5. View your panda at `/dashboard/{id}`
6. Submit a strategy in plain language
7. Start simulation

### TradingPanda 是什么？

TradingPanda 是 **Sui 链上的 AI 交易宠物养成系统**。你铸造一只熊猫 NFT，它的五轴性格在铸造时由 `sui::random` 生成并永久固化在链上。你用自然语言喂给它交易策略，它在模拟订单簿上自主练习，通过盈亏积累经验、改变情绪、进化成长。

> *"你不是在用一个 AI 工具——你是在养一个替你学交易的伙伴。"*

→ 完整产品故事：**[docs/product-description.md](docs/product-description.md)**

---

### 为什么选 Sui？

| 需求 | Sui 如何满足 |
|---|---|
| 铸造时性格不可变 | `sui::random` — 共识层内建随机数，零额外成本 |
| 经验动态增长 | `dynamic_fields` — 无需改变 struct 即可扩展 NFT 状态 |
| 模拟期间转让锁 | 对象级独占访问 — `assert!(panda.is_trading == false)` |
| 版税不可绕过的市场 | Sui Kiosk + `TransferPolicy<Panda>` |
| 去中心化 AI 记忆 | Walrus — 经验数据链下存储，`blob_id` 指针挂在 NFT 上 |
| 可验证的决策日志 | 每 50 笔交易提交一次 Merkle Root 上链 |
