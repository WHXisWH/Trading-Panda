# TradingPanda Logo Design

> Version 1.0 · 2026-06-18  
> Source assets: `docs/assets/logo/`

## Direction

The logo is a **Policy Collar Panda Agent** rendered as PNG: the real Panda Lab character sits inside a black-gold hexagonal Move-object boundary, wearing a gold TradingPolicy collar and showing restrained green market sensors.

It should feel:

- Premium but playful.
- Technical but not sterile.
- Cute enough to be a Panda, serious enough to be an autonomous trading wallet.
- Native to the current black-gold / neon-green product interface.

## Locked Principles

| Decision | Result |
|---|---|
| Main metaphor | Panda Agent wearing a Policy Collar |
| Shape system | Hexagonal badge for Move object / policy boundary |
| Expression | Calm, intelligent, slightly sly |
| Color ratio | Black-white panda base, gold ownership/collar, green live-market sensors |
| Trading signal | Subtle market pulse only, no obvious candlestick chart |
| Sui hint | Small blue sensor/proof accent, not a large Sui droplet |
| Rendering style | Raster PNG badge, Panda Lab character art, restrained glow |
| Usage priority | Product UI, navbar, favicon, prototype, docs |

## Usage Rules

- Use the icon alone in compact UI: favicon, navbar icon, app badges, cards.
- Use the wordmark in wide brand surfaces: landing hero, docs covers, pitch slides.
- Do not add meme-coin effects, oversized K-lines, full Sui logos, or old wuxia headband elements.
- Do not use green as generic decoration; green means agent activity, market freshness, or proof signal.
- Keep the icon readable at 32px before adding any future detail.
