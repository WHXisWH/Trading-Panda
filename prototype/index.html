Cyber Panda Agent Wallet OS

训练一只受 Move 约束的自主交易熊猫。

总览页是控制室大厅：先看 J0-J8 用户旅程，再进入每个旅程状态机。核心叙事不偏题： Panda 是 agent identity，PandaVault 是受限金库，TradingPolicy 是风险项圈，Chain Proof 是可验证链上动作。

Agent Wallet Thesis

The user is training a Move-constrained autonomous trading wallet.

Panda NFT = agent identity TradingPolicy = risk collar PandaVault = bounded account Chain Proof = selected PTB proof
Market source DeepBook mainnet 真实行情训练，不依赖 testnet 流动性。
Sui core Objects + PTB PandaVault / TradingPolicy / Demo executor。
Execution truth Training Ledger 纸面账本计算 PnL，Trade Fact 留证据。
Autonomy proof Agent Signer 精选 Chain Proof Moment 自动上链。

产品主循环

这条循环必须贯穿所有旅程：真实行情负责训练质量，链上对象负责约束和证明。

1. MintPanda NFT 出生，获得 agent identity。
2. CollarTradingPolicy 定义熊猫能做什么。
3. Radarmarket-monitor 监听 DeepBook mainnet。
4. LedgerTraining Ledger 执行 paper trade。
5. Proof精选 Trade Fact 触发 testnet PTB。
6. Skill复盘后更新 Skill Memory。

Sui 技术展示四象限

评委应该能在 30 秒内看到：这个项目不是套壳 AI，而是把 Sui 对象模型、PTB、DeepBook 和链上事件放进产品核心。

Object model Panda NFT / Vault / Policy 身份、容器、权限拆成清晰对象。
Autonomous action Agent Signer + PTB 用户授权 agent，Move 检查边界。
Market intelligence DeepBook real data 训练质量来自真实盘口和成交。
